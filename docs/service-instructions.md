# Service Section — Original Instructions (Brief)

The requirements given for building the Services area. The whole website must
follow the **same design pattern as the Gallery and Contact pages** (the
canonical look — a two-tone title over a curved photo hero).

---

## General

- Apply the gallery/contact design pattern across the **entire** website.
- Don't reuse the same "Claude" font/design — be creative so it **doesn't look
  AI-made**.
- Keep the **text uniform** (consistent) across the pages.
- Add **proper animation** so the experience feels enhanced as the user moves
  through each page.
- Ask if anything is needed.

---

## 1. Nav dropdown

When the mouse **hovers over "Services"** in the nav bar, show **three options as
a dropdown**:

1. Wedding Planning
2. Decoration
3. Entertainment
